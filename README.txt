INTHANINH AGRICULTURE WEBSITE
===============================

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all 3 files in the same folder.
2. Open index.html in a browser.
3. Upload the folder/files to Netlify, Vercel, GitHub Pages, or any static hosting.

Features:
- Lao / English language toggle saved in localStorage
- Responsive mobile/tablet/desktop layout
- Charcoal, rubber and agriculture products
- Product gallery + lightbox
- WhatsApp floating button + QR popup
- Google Maps at 18.008816, 102.542549
- Clickable phone/email/WhatsApp contacts

Note:
Product, gallery, charcoal, rubber and agriculture cards use local photos. QR images may still use external services unless replaced locally.
